# Operación Ciberguardia

Juego educativo sobre el Convenio de Budapest.

## Ejecutar con Docker

En esta carpeta, ejecutar:

```powershell
docker compose up --build
```

Luego abrir `http://localhost:8080`.

Para detener el servicio:

```powershell
docker compose down
```

El contenedor usa Nginx y publica la aplicación en el puerto `8080`.
